# Pokémon Weight Analysis

A beginner data analysis project using Python and Pandas. It answers one question: which Pokémon type is the heaviest on average?

**Tools used:** Python, Pandas, Matplotlib, Google Colab

**Files:**
- `pokemon_weight_report.ipynb`: the full report with code, chart and findings
- `data.csv`: the Pokémon dataset

**Main finding:** Rock-type Pokémon are the heaviest on average, and Ghost-type are the lightest.
